# 🏠 Airbnb Data Analysis — Python & SQL

## 📊 Project Overview

This project analyzes Airbnb listings in New York City using **Python and SQL**.

The analysis focuses on Airbnb prices, room types, neighbourhoods, availability, reviews, hosts, and geographic patterns.

---

## 🛠️ Tools Used

* 🐍 Python
* 🗄️ SQL
* 📓 Jupyter Notebook
* 🐼 Pandas
* 📊 Matplotlib
* 📈 Seaborn
